# 🤖 OpenCode Web Agent on Heroku

Repository ini digunakan untuk melakukan instalasi instan **OpenCode Web UI** ke Heroku menggunakan teknologi Container otomatis. Agen Anda akan langsung diamankan dengan sistem login *username* & *password*.

## 🚀 Instalasi Instan

Klik tombol di bawah ini untuk memulai proses deploy otomatis langsung ke akun Heroku Anda:

[![Deploy to Heroku](https://www.heroku.com/wp-content/uploads/2025/03/button.png)](https://heroku.com/deploy)

## 🔑 Konfigurasi Setelah Klik
Saat halaman penginstalan Heroku terbuka, Anda hanya perlu mengisi formulir yang disediakan:
1. **App Name**: Nama aplikasi web unik Anda.
2. **OPENCODE_WEB_USERNAME** & **PASSWORD**: Kredensial untuk mengamankan link publik Anda.
3. **API Key**: Masukkan salah satu API Key AI Anda (OpenCode Zen, OpenAI, atau Anthropic) agar agen bisa bekerja.
